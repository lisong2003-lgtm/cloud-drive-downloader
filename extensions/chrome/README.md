# 通用 pan 下载插件

## 是什么

通用浏览器插件把**用户复制、选中或粘贴的链接**投递到 pan 服务下载。服务地址可以是：

- 本机：`http://127.0.0.1:<port>`
- NAS：`http://<nas>:<port>`
- 服务器：`http://<server>:<port>`

插件不读取网页登录态，不解析分享页，不上传账号密码；只 POST 用户主动提供的链接和可选参数。保存的提取码仅保留在浏览器本地，可通过弹窗清空。

## Chrome 安装

1. 启动目标服务：`python3 <pan-root>/scripts/pan.py serve --host 127.0.0.1 --port <port>`。
2. 打开 `chrome://extensions`。
3. 开启右上角「开发者模式」。
4. 点「加载已解压的扩展程序」，选择本目录。
5. 固定到工具栏，打开弹窗填写服务地址并点「保存地址」。

## Edge 安装

1. 启动目标服务。
2. 打开 `edge://extensions`。
3. 开启左侧「开发人员模式」。
4. 点「加载解压缩的扩展」，选择本目录。
5. 固定到工具栏，打开弹窗填写服务地址并点「保存地址」。

## 使用

- **复制链接**：复制网盘分享链接或 HTTP 直链，插件提取第一条 URL。
- **右键发送**：选中链接文字或右键页面，选择「发送 网盘链接 到 pan 下载」。
- **弹窗投递**：点击图标，手动粘贴链接，填写提取码、目标目录、引擎、档次。

## 测试连接

1. 打开插件弹窗，在「服务地址」填入本机 / NAS / 服务器地址。
2. 点「保存地址」。
3. 点「测试连接」。失败时检查 `pan serve` 是否运行、端口是否一致、防火墙是否放行。

## 安全性

- `host_permissions` 用于访问你配置的服务地址；不读取网页登录态。
- 不在插件里存储账号密码；不读取 Cookie、Token 或本地网盘客户端状态。
- 默认只下载不上传。
