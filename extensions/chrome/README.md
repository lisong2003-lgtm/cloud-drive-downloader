# Chrome 扩展：多网盘统一下载（本机桥接）

## 是什么

复制/选中**网盘分享链接或 HTTP 直链**后，一键发送给本机 `pan serve`（默认
`127.0.0.1:17890`）进行下载。扩展本身**不读取网盘页面登录态**，只把链接和用户
填写的可选参数 POST 到本机服务，再由 `scripts/pan.py get --live` 后台下载。

## 安装（开发者模式）

1. 先确保本机已运行：`python3 scripts/pan.py serve`
2. 打开 Chrome，访问 `chrome://extensions`
3. 打开右上角「开发者模式」
4. 点「加载已解压的扩展程序」，选择本目录 `extensions/chrome/`
5. 固定到扩展栏即可使用

## 使用

- **复制链接**：在任一网页复制网盘链接，扩展会捕获 clipboard 文本并提取第一个 URL；
- **右键发送**：选中链接文字或直接右键页面，选择「发送 网盘链接 到 pan 下载」；
- **弹窗**：点击扩展图标，可手动粘贴链接，并填写提取码、目标目录、引擎、档次。

## 安全性

- `host_permissions` 仅 `http://127.0.0.1:17890/*`，不会访问任何云盘域名。
- 不在扩展里存储账号密码；提取码只存本地 `chrome.storage.local`（用于下次右键快捷发送），
  并可通过弹窗清空。
