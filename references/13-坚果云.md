# 坚果云（WebDAV）

## 链接形态

- 坚果云分享页：`https://www.jianguoyun.com/p/xxxx`。
- WebDAV 文件地址：`https://dav.jianguoyun.com/dav/文件夹/文件.zip`。
- 分享页本身不等于 WebDAV 直链；最稳妥是拿到自己账号里的 WebDAV 路径。

## 推荐通道

| 通道 | 适用 | 说明 |
|---|---|---|
| 坚果云 WebDAV | 已登录的自己的文件 | 支持 `curl -C -` 断点续传 |
| 坚果云网页/客户端 | 前置操作 | 先将分享保存到自己的坚果云 |
| AList WebDAV | 已有 AList 时 | 也可以把坚果云挂到 AList 后下载 |

## 配置

1. 在坚果云网页版 → 安全选项 → 第三方应用管理，生成“应用密码”（不是登录密码）。
2. 记录 WebDAV 地址，通常为 `https://dav.jianguoyun.com/dav/`。
3. 把应用密码写入本机系统凭据库（macOS Keychain / Windows Credential Manager / Linux secret-tool），再把地址和账号写入配置：

```bash
# 在用户自己的本机终端执行；密码不回显、不进聊天、不进命令行
python3 scripts/pan.py secret set engine.webdav

python3 scripts/pan.py set \
  --webdav-url "https://dav.jianguoyun.com/dav" \
  --webdav-user "你的坚果云账号"
```

如果已有旧配置里的明文密码，执行：

```bash
python3 scripts/pan.py secret migrate
```

4. 下载自己的文件：

```bash
python3 scripts/pan.py get "https://dav.jianguoyun.com/dav/文件夹/文件.zip" --dry-run
python3 scripts/pan.py get "https://dav.jianguoyun.com/dav/文件夹/文件.zip"
```

也可以给分享链接配 `--path`，但前提是该路径在你已配置的 WebDAV 账号中确实存在。

## 免费 / 会员

- 免费账号：有上传流量/空间和速度限制；本工具不做绕过。
- 会员：`set-drive jianguoyun --tier vip` 只调整调度并发，平台限制仍以坚果云为准。

## 常见错误

| 现象 | 处理 |
|---|---|
| 401/403 | 用“应用密码”，不要用网页登录密码 |
| 路径不存在 | 先用浏览器/客户端确认 WebDAV 相对路径 |
| 分享链接无法直下 | 先保存到自己坚果云，再走 WebDAV |

## 风险提示

应用密码只存在本机系统凭据库；共享电脑上不要保存凭据，也不要通过聊天发送账号密码。
