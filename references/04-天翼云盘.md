# 天翼云盘

## 两条通道

| 通道 | 适用 | 说明 |
|---|---|---|
| 官方开放平台 | 企业/合作方 | `api.cloud.189.cn`，需申请与审核，个人接入门槛高 |
| AList 天翼驱动 | 个人自用 | Cookie/账号登录，配置快 |

## 用 AList 接入

1. 启动 AList，添加“天翼云盘”存储，按驱动提示填 Cookie 或账号信息。
2. 登记 AList 地址：

```bash
python3 scripts/pan.py set --alist-url "http://127.0.0.1:5244"
```

3. 分享链接先转存到自己天翼账号，再按 AList 路径下载：

```bash
python3 scripts/pan.py get "<分享链接>" --path "/天翼云盘/目标文件夹" --dry-run
python3 scripts/pan.py get "<分享链接>" --path "/天翼云盘/目标文件夹"
```

## 免费 / 会员

- 免费账号：天翼通常有一定免费速度，高峰期限速；默认单线程。
- 会员：`set-drive tianyi --tier vip`，由引擎按能力提高并发。

## 常见错误

| 报错 | 处理 |
|---|---|
| Cookie 失效 | AList 中重新登录天翼存储 |
| 路径不存在 | 先在 AList 里刷新目录，确认挂载路径 |
| 分享转存失败 | 登录天翼网页版手动转存一次再重试 |
