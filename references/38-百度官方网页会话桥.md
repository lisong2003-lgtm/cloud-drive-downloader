# 38 · 百度官方网页会话桥

> v0.16.0 默认百度引擎：`baiduweb`。目标是不安装桌面客户端、不粘贴 Cookie，直接处理官方分享页。

## 1. 命令

```bash
# 探测 / 列目录
python3 scripts/pan.py probe "https://pan.baidu.com/s/1xxxx?pwd=1234" --json

# 下载到指定目录（文件夹保持同名结构）
python3 scripts/pan.py get "https://pan.baidu.com/s/1xxxx?pwd=1234" \
  --to "/目标下载目录/百度网盘" --live

# 显式提取码
python3 scripts/pan.py get "https://pan.baidu.com/s/1xxxx" --pwd 1234 --to /目标目录 --live
```

## 2. 识别字段

`plan.detected` / 探测结果包含：

| 字段 | 说明 |
|---|---|
| `driver` | `baidu` |
| `title` | 分享标题 |
| `share_id` | 官方分享 ID；敏感值不会输出 |
| `share_uk_present` | 是否拿到分享用户 ID；只输出布尔值 |
| `login_state` | 匿名 / 登录 / 受限等页面状态 |
| `password_required` | 是否仍需要提取码 |
| `files_total` | 递归后的文件数量 |
| `total_bytes` | 所有待下载文件字节总大小 |

## 3. 执行规则

1. 链接里的 `?pwd=` 自动提取；没有时用 `--pwd`。
2. 提取码通过官方接口提交，提取结果只留在进程内会话。
3. 分享根只有一个文件夹时，直接展开该文件夹；否则在本地创建分享根同名目录。
4. 目录分页递归列出，生成本地相对路径。
5. 文件按序号拆分；每个文件独立解析直链、下载、记录结果。
6. 直链请求失败自动重试；官方平台限制不反复冲击。
7. `.part` 文件用于断点续传；完成后替换成最终文件。
8. 同路径、同大小、已完整的文件跳过。
9. 进度回调输出当前文件、总进度、完成数、失败数、速度、剩余时间、状态和本地路径。

## 4. 接口错误边界

| 官方返回 | 网盘通错误码 | 行为 |
|---|---|---|
| `errno=-20` / `errno=-21` | `captcha_required` | 安全失败；不绕过验证码 |
| `errno=118` | `platform_denied` | 安全失败；不绕过“违规操作”限制 |
| 登录类错误 | `auth_required` | 安全失败；引导去官方网页登录，不粘贴 Cookie |
| 提取码错误 | `password_invalid` | 停止；核对提取码 |
| 会员 / 付费 | `member_required` | 安全失败；不绕过 |

## 5. 安全

- 不读取浏览器 Cookie，不提供 `BDUSS` / `STOKEN` / Cookie 导入。
- 会话 `CookieJar` 只存在内存，不持久化。
- `sign`、`timestamp`、`jsToken`、`sekey`、Cookie 不打印、不落日志。
- Web API 的 URL 会脱敏 `pwd` 等敏感参数。
