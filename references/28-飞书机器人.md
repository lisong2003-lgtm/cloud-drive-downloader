# 飞书机器人（第 3 步）

## 能做什么

把网盘链接从手机飞书里「发给你自己的机器人」→ 机器人桥自动把链接转发给本机/NAS 的 pan 下载服务 → 飞书收到“已开始下载”并附上 Web 实时进度地址。

## 飞书两种接入（先说清边界）

| 方式 | 能发通知 | 能收到你发的消息 | 是否需要公网回调 |
|---|---|---|---|
| 群机器人 Webhook | ✅ | ❌ | 不需要（飞书出站到你的 URL） |
| 自建应用 App + 事件订阅 | ✅ | ✅ | 需要（飞书事件推送要到你的公网地址） |

- **群机器人 Webhook**：最简单，只要一个 Webhook URL，适合“下载完成通知我”。
- **自建应用 + 事件订阅**：才能实现“发链接→自动下载”。飞书事件可以是**事件回调 URL** 或 **WebSocket 长连接接入**。

## 通知（群机器人 Webhook，已支持）

保存 Webhook 地址到系统凭据库，然后发送即可：

```bash
python3 scripts/pan.py secret set notify.feishu --stdin   # 粘贴飞书群机器人 Webhook URL
python3 scripts/pan.py notify --channel feishu --title "下载完成" --body "已落盘" --send
```

`--channel` 可选项已加入 `feishu`；payload 使用飞书文本消息 `{"msg_type":"text","content":{"text":...}}`。

## 发链接→自动下载（事件回调桥）

### 1. 在飞书开放平台建应用
- 打开 [open.feishu.cn](https://open.feishu.cn)，创建“企业自建应用”（个人版也可以）。
- 开启“机器人”能力，获得 `APP_ID` / `APP_SECRET`（秘钥存本机系统凭据库，不写进 config/Git/聊天）。
- 配置事件订阅：选择 `接收消息 im.message.receive_v1`，回调地址指向桥的 `/feishu/callback`。

### 2. 启动桥（本机或 NAS）
```bash
python3 scripts/feishu_bot.py --check                       # 离线自检，不联网
python3 scripts/feishu_bot.py --host 0.0.0.0 --port 9001    # 常驻事件回调服务
python3 scripts/feishu_bot.py --host 0.0.0.0 --port 9001 --target http://192.168.1.10:17890
```
- `--target` 是 pan `serve` 的地址和端口。默认 `http://127.0.0.1:17890`。
- 收到消息后自动抽取 `http(s)` 链接和“提取码/密码/pwd/提取码：”后的 4-6 位码，POST 到 `serve` 的 `/api/download`。
- 返回后飞书侧会看到“✅ 已开始下载”或失败原因。

### 3. 公网回调地址（关键前提）
飞书需要能用 HTTPS/公网地址回调到你。两种常见方式：

- **NAS/家庭网络**：用 SSH 反向隧道，把本机 `9001` 暴露到有公网的 VPS：
  ```bash
  ssh -R 9001:127.0.0.1:9001 user@public-vps
  # 飞书回调地址填：http://<VPS_公网IP>:9001/feishu/callback
  ```
- **有公网 IP 的 NAS/VPS**：直接填 `http://<公网IP>:9001/feishu/callback`，并确认防火墙放行该端口。
- 正式生产建议在 VPS 前加 HTTPS（Caddy/Nginx 反代），飞书事件订阅支持加密 (Encrypt Key)；本脚本当前未内置加密解密，启用加密键时会提示需在接入层处理，避免把原始负载打打印出来。

## 安全边界

- 秘钥（APP_SECRET / Webhook / Encrypt Key）一律走 `pan secret set` 系统凭据库，不落 config、不落聊天、不落 Git。
- 桥只处理“你主动发给机器人”的链接；不会主动读网盘页面登录态。
- 公司内部文件不上传第三方云盘；飞书机器人只转发你主动提供的下载链接。
- 公网暴露前务必先用 SSH 隧道/VPS 反代，不要让下载服务直接裸奔公网。
