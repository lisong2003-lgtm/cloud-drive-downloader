# 阿里云盘

## 两条通道

| 通道 | 适用 | 说明 |
|---|---|---|
| 官方开放平台 API | 愿意注册应用、要长期稳定 | 需申请 `client_id/client_secret`，OAuth 授权 |
| AList 挂载 | 想快点用起来 | 用 refresh_token 或扫码授权把网盘挂到 AList |

## 通道 A：官方开放平台

1. 到阿里云盘开放平台申请应用，拿到 `client_id`、`client_secret`。
2. 浏览器访问授权页，把回调拿到的 `auth_code` 换成 `refresh_token`。
3. 把 token 写入本机凭据文件（不要贴在聊天里）。

官方接口对分享链接的处理以平台当期文档为准；若分享链接接口受限，改用“转存到自己账号→列目录→下载”的流程。

## 通道 B：AList（推荐起步）

1. 安装并启动 AList，记下地址（如 `http://127.0.0.1:5244`）。
2. 在 AList 管理界面“存储”里添加阿里云盘，按提示扫码或填 refresh_token。
3. 把 AList 地址登记给本技能：

```bash
python3 scripts/pan.py set --alist-url "http://127.0.0.1:5244"
python3 scripts/pan.py set --alist-user <用户名>
```

4. 分享链接先在浏览器转存到自己账号，再按 AList 中挂载路径下载：

```bash
python3 scripts/pan.py get "<分享链接>" --path "/阿里云盘/目标文件夹" --dry-run
```

## 免费 / 会员

- 免费账号：下载限速与并发限制由阿里云盘决定；默认单线程。
- 会员：`python3 scripts/pan.py set-drive aliyun --tier vip`，AList/引擎支持时提高并发。

## 常见错误

| 报错 | 处理 |
|---|---|
| `token 过期` | AList 里重新授权阿里云盘 |
| `分享链接打不开` | 先转存到自己账号再下载 |
| `AList 未配置` | 运行 `pan set --alist-url ...` |
