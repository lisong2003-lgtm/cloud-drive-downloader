# 通用使用说明

## 这个技能解决什么

用户给出网盘分享链接、转存文件夹或 HTTP 直链时，技能统一识别网盘、规划下载目录、调用共享下载引擎。用户不需要逐个安装百度、夸克、天翼等官方客户端；共享引擎（AList / rclone / BaiduPCS-Go / 夸克 CLI / WebDAV / aria2 / curl）由技能统一调用。

注意：部分平台仍要求一次官方网页授权、扫码、OAuth 或 Cookie 登录；这是网盘本身的账号要求，不属于“安装各家客户端”。技能不绕过验证码、风控或平台限速。

## 首次配置

```bash
python3 scripts/pan.py init
python3 scripts/pan.py doctor
python3 scripts/pan.py dirs
```

- 配置文件：macOS/Linux 默认为 `~/.config/pan-downloader/config.json`；Windows 为 `%APPDATA%\pan-downloader\config.json`。
- 配置只保存 URL、用户名、目录、引擎路径和 `credential:名称`/旧 `keychain:名称` 引用，不保存账号密码明文。
- 日志：macOS 为 `~/Library/Logs/pan-downloader.log`；Windows 为 `%LOCALAPPDATA%\pan-downloader\logs\pan-downloader.log`；日志会打码凭据。

## 先测试再下载（不实际下载文件）

拿到链接先跑一次测试，能提前发现缺依赖、目录不可写或提取码缺失：

```bash
python3 scripts/pan.py test "<网盘分享链接>" --pwd <提取码>
python3 scripts/pan.py test "<链接>" --json      # Agent 用，输出 JSON 结论
```

`pan login <盘名> --open` 可直接打开该网盘的授权教程；网盘本身的扫码/网页登录仍按官方要求完成，技能不绕过风控。

## 凭据保护（重点）

账号密码、Cookie、Token、BDUSS 等敏感值默认只允许进入当前操作系统的系统凭据库：macOS Keychain、Windows Credential Manager，或 Linux 的 `secret-tool`。技能自身不保存明文。

```bash
# 推荐：本机交互输入，不在命令行、聊天、日志中出现明文
python3 scripts/pan.py secret set engine.webdav
python3 scripts/pan.py secret set engine.alist

# 脚本/agent：从 stdin 读取
printf '%s\n' "$WEBDAV_PASSWORD" | python3 scripts/pan.py secret set engine.webdav --stdin

# 只保存非敏感配置；密码字段保存为系统凭据库引用
python3 scripts/pan.py set \
  --webdav-url "https://dav.jianguoyun.com/dav" \
  --webdav-user "账号"
python3 scripts/pan.py set --alist-url "http://127.0.0.1:5244" --alist-user "AList账号"
```

旧配置若已有明文：

```bash
python3 scripts/pan.py secret list
python3 scripts/pan.py secret check engine.webdav --json
python3 scripts/pan.py secret migrate
```

迁移失败时不要退回保存明文；请在正常终端授权系统凭据库后重试。账号名可以与用户确认，但不要在 agent 聊天里粘贴密码、Cookie 或 Token。

## 常用命令

```bash
# 识别链接
python3 scripts/pan.py detect "<链接>"

# 预演（不下载，输出计划）
python3 scripts/pan.py get "<链接>" --pwd <码> --dry-run

# Agent/脚本用的无凭据 JSON 计划
python3 scripts/pan.py get "<链接>" --dry-run --json

# 实际下载
python3 scripts/pan.py get "<链接>" --pwd <码>

# Windows PowerShell（在 scripts 目录）
.\\pan.ps1 get "<链接>" --pwd <码>
pan.cmd get "<链接>" --pwd <码>

# 下载到远程 NAS / 私有存储
python3 scripts/pan.py remote add nas --kind ssh --host 192.168.1.10 --user lis --root /volume1
python3 scripts/pan.py remote deploy nas
python3 scripts/pan.py remote get nas "<链接>" --pwd <码> --dry-run
python3 scripts/pan.py get "<链接>" --remote nas --dry-run --json

# 指定目录 / 指定引擎 / 账号等级
python3 scripts/pan.py get "<链接>" --to "/Volumes/PanDownloads/资料"
python3 scripts/pan.py get "<链接>" --engine aria2
python3 scripts/pan.py set --tier auto
python3 scripts/pan.py set-drive 115 --account-tier vip
python3 scripts/pan.py set-drive 115 --tier-detector '检测命令'
python3 scripts/pan.py get "<链接>" --tier vip
```

## 已登记网盘

首批：百度、阿里云盘、夸克、天翼、迅雷。

扩展批：115、123 云盘、移动云盘/和彩云、联通沃盘、UC 网盘、PikPak、坚果云、OneDrive/SharePoint、Google Drive、Dropbox、腾讯微云、蓝奏云、悟空、豆包新盘、Mega、TeraBox、pCloud、Proton Drive、Yandex Disk、MediaFire、Trainbit、光雅盘、飞鸡云、闪电盘、城通网盘。

新域名先用 `detect` 检查；不在清单里的网盘按下方“扩展”接入。

## 目录规则

- macOS 根目录优先 `/Volumes/PanDownloads/网盘下载`；未挂载时依次尝试 `/Volumes/PanOffice/网盘下载`、`~/Downloads/网盘下载`。
- Windows 默认 `%USERPROFILE%\Downloads\网盘下载`；Linux 默认 `~/Downloads/网盘下载`。
- 任务目录：`<根目录>/<网盘名>/<日期>-<链接尾号或文件名>/`。
- 用户可通过 `pan set --root "<目录>"` 或 `pan get ... --to "<目录>"` 指定目录。
- 同名文件用断点续传；工具不做覆盖删除，也不做危险清理。

## 账号等级：免费 / 会员 / 自动探测

| 模式 | 行为 |
|---|---|
| `tier=auto`（默认） | 先读 `drives.<盘>.account_tier`；没有则执行已配置的 `tier_detector`；仍无结果时按免费账号处理 |
| `tier=free` | 并发 1、重试 3、断点续传 |
| `tier=vip` | 并发按引擎能力和 `max_connections_vip` 调整 |

账号等级不能从账号名或链接本身可靠推断；必须由登录后的网盘接口、AList/CLI 输出或用户确认结果提供。会员也不等于所有场景“不限速”，实际速度以各网盘官方对会员的规则为准，本工具不绕过平台限制。

```bash
# 记录已确认的会员账号
python3 scripts/pan.py set-drive 115 --account-tier vip

# 让某个引擎把 free/vip 写到标准输出
python3 scripts/pan.py set-drive 115 --tier-detector '你的等级检测命令'
```

`tier_detector` 输出含 `vip/会员/svip/premium` 判为会员，含 `free/免费/普通` 判为免费；不明确时回退免费。

## 共享引擎与递归下载

多数扩展网盘需要先把分享转存到自己的网盘，并在 AList 中挂载：

```bash
python3 scripts/pan.py set --alist-url "http://127.0.0.1:5244" --alist-user "AList账号"
python3 scripts/pan.py set --rclone-remote alist
python3 scripts/pan.py get "<链接>" --path "/挂载名/子目录" --dry-run
```

要递归下载目录，建议先配置 rclone 的 WebDAV remote（remote 名要和 `--rclone-remote` 一致）。技能会按账号等级设置 `--transfers`：免费 1，会员按 `max_connections_vip`：

```bash
rclone config
python3 scripts/pan.py set --engine-name rclone --engine "$(command -v rclone)"
```

坚果云等 WebDAV：

```bash
python3 scripts/pan.py secret set engine.webdav
python3 scripts/pan.py set \
  --webdav-url "https://dav.jianguoyun.com/dav" \
  --webdav-user "账号"
```

## 引擎选择顺序

1. 某网盘在 `drives.<盘>.engine_command` 配了自定义命令 → 用自定义。
2. 命令行 `--engine` 指定 → 用指定引擎。
3. 否则用内置推荐引擎（见 SKILL.md 对照表）。

## 排障

| 现象 | 处理 |
|---|---|
| `缺少依赖：BaiduPCS-Go` | 看 `references/01-百度网盘.md` 安装并用 `pan set --engine-name baidupcs --engine <路径>` 登记 |
| AList 路径为空 | 先在 AList 里挂载网盘并转存，再 `--path /挂载名/子目录` |
| 目录只下到一个文件 | 配置 rclone remote，再使用 `--path` 递归下载 |
| Cookie/Token 过期 | 回官方页面重新登录，更新本机凭据 |
| 下载速度只有几十 KB/s | 先确认账号等级和平台限速；自动探测不到时按免费处理，工具无法绕过平台限速 |
| 链接识别失败 | 用 `--engine` 指定引擎，或在 `extensions` 里补域名 |
| 401/403 | 重新授权；不要用主号硬试，不要绕过验证码 |
| 系统凭据库读取失败 | 在正常终端执行 `secret check` 并授权 Keychain/Credential Manager/secret-tool；不要退回明文 |
| Windows 提示找不到 Python | 重新安装 Python 并勾选 Add python.exe to PATH；或运行 `py -3 scripts\pan.py doctor` |
| 远程 check 失败 | 检查 SSH/密钥、rclone remote、WebDAV/SMB 地址和根目录；详见 `references/21-远程NAS与私有存储.md` |

## 安全边界

- 凭据文件不要放进 Git、网盘或聊天记录。
- 公司资料只下载到本机/公司介质，不上传任何云盘。
- 分享链接涉及付费内容时，仅下载你有权访问的资源。
- 只使用官方或维护中的第三方引擎；失效时更新 AList/CLI，不修改平台限制。

## 报告与完成钩子（v0.6.1 新增）

- `pan.py get "<链接>"` 实际下载完成后，会在目标目录写出 `下载报告.json`：
  字段包括 `ok / url / drive / engine / tier / target / started / finished / elapsed / steps / missing / warnings`；
  `steps[]` 每项含步骤序号、引擎、说明、打码后的参数、退出码、耗时。全量执行成功时 `ok=true`。
- 报告目录可改：在 `~/.config/pan-downloader/config.json` 的 `http.report_dir` 填写目录（不填则随任务目录写）。
- 完成钩子：在 `http.on_complete_hook` 填一条命令模板，下载成功后在目标设备执行，例如：
  `rsync -rt --no-perms {target}/ /Volumes/PanDownloads/归档/`
  支持占位符：`{target}` `{report}` `{drive}` `{engine}` `{tier}` `{url}`。占位符不会做 shell 转义，模板中务必自行加引号。
- 后处理链样板：`scripts/post_media.sh`（AUTO=0 默认预览，改 1 生效；已内置 ZIP/TGZ 解压与 Jellyfin/Emby 入库占位）。
- 事件流：`pan.py get "<链接>" --events` 会在执行每个引擎步骤前/后各输出一行 JSON（NDJSON），
  适合 Agent 或脚本逐条消费；不会打印任何账号密码/Token。

## Range 分片下载（v0.6.1-R2 新增）

- 用途：单个大体积 http/https 直链文件提速；默认关闭。
- 开启方式二选一：
  1. 命令级：`pan.py get "<直链>" --split 4`
  2. 配置级：`~/.config/pan-downloader/config.json` 的 `http.range_split=true` + `http.range_split_connections=4`
- 生效条件：先用 `curl -sI -L` 探测，服务端必须返回 `Content-Length` 并支持 `Accept-Ranges: bytes`；任一不满足就自动回退整文件下载（行为与未启用一致）。
- 流程：按字节范围启动多个 curl 并行分段（`-r`），成功后按顺序合并到目标文件并做字节数校验；分片失败或校验不一致时返回非 0，并在 `下载报告.json` 的 `steps[]` 里记录每段 rc/耗时。
- 边界：只对直链适用；AList 目录递归、WebDAV、百度/夸克等引擎不因该开关改变行为。


## 常见错误提示（v0.6.1-R9 新增）

执行 `get` 失败时，终端和 `下载报告.json` 的 `steps[].hint` 会输出人话版中文动作提示，不再只有退出码：

| 场景 | 提示 |
| --- | --- |
| 超时（rc=124） | 网络慢或文件大；重跑会自动断点续传 |
| 命令不存在/不可执行（rc=126/127） | 先运行 `pan.py doctor` 检查并安装依赖 |
| 连接失败（rc=7） | 检查网络/分享链接是否有效，必要时重新登录该网盘 |
| 服务器返回非 2xx（rc=22，401/403） | 授权过期、提取码错误或无权限，重新登录该网盘 |
| WebDAV | 更新 `engine.webdav` 密码：`pan.py secret set engine.webdav --stdin` |
| 百度网盘 | 先 `pan.py login baidu`，分享链接需先转存到自己网盘 |
| 夸克网盘 | Cookie 可能已失效，先 `pan.py login quark` |

判断不了的错误保持原文退出码，不做猜测。提示同时写入 `下载报告.json`，方便 Agent 后续自动重试/通知。


### 定时 / 低峰下载（骨架）

- `pan.py get "<链接>" --at 02:30` 到点才开始；未传则读 `http.schedule_at`（config 里填 HH:MM）。
- 对白天带宽紧张的超大文件，建议排到凌晨；骨架为 CLI 阻塞等待，重启后需重新提交。


### 网页下载助手（一键）

```bash
sh scripts/pan_web.sh            # 启动本机服务 + 剪贴板监听 + 打开网页
# 或分开控制：
python3 scripts/pan.py serve     # 常驻：Web UI/PWA/API
python3 scripts/clipboard_monitor.py  # 常驻：剪贴板自动投递
```

- 浏览器打开 `http://127.0.0.1:17890/`，首页最上方「粘贴链接开始下载」，提交后自动跳转 `/live` 看实时进度（速度/剩余时间/曲线）。
- 剪贴板监听：复制任意外部文本后，脚本会从中抽取第一条 http(s) 链接自动投递；同一链接 10 分钟内不重复投递；`--once` 可只检查一次。
- `POST /api/download` 返回 `pid / live_url / home_url`，Agent 把它发给用户即可打开进度页。
