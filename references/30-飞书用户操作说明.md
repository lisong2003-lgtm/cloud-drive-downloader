# 飞书用户操作说明（发布后，面向普通成员）

> 这篇说明讲清楚：**其他同事/用户拿到这个下载技能后，怎样用飞书来下载文件。**
> 分两类人看：使用的人看“第 1 部分”，帮忙部署的人看“第 2 部分”。

---

## 第 1 部分：我是普通用户，在飞书里怎么下载？

### 1.1 你只需要做三件事
1. 在飞书里找到管理员公布的机器人（应用名，例如“下载助手”），点进去。
2. 在聊天框里粘贴网盘分享链接，直接发送；有提取码就在同一段消息里写：`提取码：1234`。
3. 等机器人回复 **“✅ 已开始下载：… /live 地址”**，然后把 /live 地址（通常是 `http://…:17890/live`）复制到浏览器，就能看实时速度、剩余时间和完成大小。

下载完成后的文件在哪：**找管理员询问下载目录**（默认在他的电脑/NAS 的“网盘下载”文件夹）。

### 1.2 常见情况
- **机器人不回复**：先确认链接是否完整；再确认网盘是否要求扫码/登录（管理员需先完成一次授权）。
- **提示提取码错误**：把提取码和链接一起发，例如 `https://pan.baidu.com/s/xxx 提取码：abcd`。
- **我自己没装任何东西，能用吗？**：可以。下载服务是管理员那边常驻运行的，你只用飞书发链接即可。

## 第 2 部分：我是部署者/管理员，怎么给成员开飞书下载？

### 2.1 需要一台“常开”的电脑或 NAS
- 这台机器运行 Python + 本技能（`scripts/pan.py`）。
- 要先跑一次配置：`python3 scripts/pan.py setup --apply`。
- 启动两个服务（一个 Web 控制台，一个飞书桥）：
  ```bash
  # 终端1：网页下载助手（任务中心 + 实时速度）
  python3 scripts/pan.py serve --host 0.0.0.0 --port 17890
  # 终端2：飞书事件桥（收到链接→转给网页下载服务）
  python3 scripts/feishu_bot.py --host 0.0.0.0 --port 9001 --target http://127.0.0.1:17890
  ```

### 2.2 飞书侧
- 在飞书开放平台创建**自建应用**，开启机器人能力，配置**接收消息事件**（`im.message.receive_v1`）。
- 把回调地址指向桥的 `/feishu/callback`（公网可达；或用 SSH 反向隧道/VPS 转发）。
- 发布应用后，通知成员在飞书里搜索应用名并发送链接。

### 2.3 先小范围测试
- 你自己先给机器人发一条链接，确认回复“已开始下载”。
- 再放 1-2 个同事测试，没问题再全体开放。

## 边界与安全（一定告诉成员）

- **这不是下载“破解”工具**：免费网盘仍按官方限速/风控执行，不会更快。
- 不是所有网盘都能飞书发一条就下：有些要管理员先在本机完成扫码授权；这部分登录态存在服务端，不上传云端。
- 成员只能让文件下载到**管理员的机器/NAS**，所以要**只给信得过的成员用**，并约定好下载目录。
- 不要把公司机密的资料通过机器人转发到第三方云；机器人转发的是“你主动发的下载链接”，不是文件本身。

## 快速疑难点对照

| 现象 | 原因/做法 |
|---|---|
| 飞书找不到机器人 | 管理员还没发布应用，或名称不对；找管理员要应用名 |
| 消息发出后 10 秒没回 | 桥没起来，或回调地址不公网可达；找管理员看 `/tmp/pan_remote_*`/服务日志 |
| 回复“已开始下载”但没文件 | 问管理员下载目录，或看任务中心是否有失败任务 |
| 想暂停/继续 | 打开网页 `/` 任务中心，运行中的任务有“暂停/继续”按钮 |
| 公司内网/无公网 | 用 SSH 反向隧道把 `9001` 暴露给有公网的 VPS，飞书回调填 VPS 地址 |
