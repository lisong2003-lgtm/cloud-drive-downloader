# 联通沃盘

## 链接形态

- `https://wopan.wo.cn/...`、`https://pan.wo.cn/...`。
- 常见为分享链接，可能要求登录联通账号。

## 推荐通道

| 通道 | 适用 | 说明 |
|---|---|---|
| AList 联通沃盘驱动 | 个人自用 | 用 Cookie/账号登录挂载 |
| 联通沃盘网页/客户端 | 前置操作 | 分享先转存到自己账号 |
| 自定义 CLI | 驱动不支持时 | 用 `engine_command` 接入已有工具 |

## 登录

1. 浏览器登录沃盘，按 AList“联通沃盘”驱动的提示获取 Cookie/登录信息。
2. 登记 AList：

```bash
python3 scripts/pan.py set --alist-url "http://127.0.0.1:5244"
```

3. 转存后用路径下载：

```bash
python3 scripts/pan.py get "<沃盘分享链接>" --path "/联通沃盘/目标文件夹" --dry-run
python3 scripts/pan.py get "<沃盘分享链接>" --path "/联通沃盘/目标文件夹"
```

## 免费 / 会员

- 免费账号：由沃盘决定速度和并发；本工具默认单线程、断点续传。
- 会员：`set-drive wopan --tier vip` 只调整调度并发，不做限速绕过。

## 常见错误

| 现象 | 处理 |
|---|---|
| Cookie 失效 | 重新登录沃盘并刷新 AList 存储 |
| 分享无法打开 | 确认分享有效期和提取码 |
| 识别失败 | 用 `detect` 检查域名，或配置 `engine_command` |

## 风险提示

登录态不要外传；如果 AList 驱动不支持当前沃盘版本，改用官方客户端或自定义命令。
