## 3. 明确“不支持 / 需接入”的盘名

以下盘名未写入 `DRIVES` 注册表，本 Skill **不识别、不承诺可下载**；遇到这些链接视为“不支持/需接入”，需先按 `references/06-扩展新网盘.md` 接入后才能使用，不得当作 HTTP 直链直接抓取分享页：

- 新浪微盘（weibo 分享盘）
- 华为网盘（好盘 / dbank）
- 360 云盘 / 360 安全网盘
- 永硕 E 盘 / 民工网盘
- 纳米盘
- 好盘 / 快盘（金山）
- 轻舟网盘、极速盘、龙猫网盘、蜜蜂网盘、千脑云盘
- 任何你搜不到官方稳定接口的“小众网盘”

## 4. 判定与降级规则（不多承诺）

1. `pan.py detect <链接>`：命中 `DRIVES` 才返回网盘 key；未命中但为 http(s) 会回退 `direct`。
2. 若链接明显是【云盘分享页】却回退成 `direct`（例如上面第 3 节列出的盘名）：**不允许当作直链下载**，输出“不支持/需接入：<盘名>”，给出 `references/06-扩展新网盘.md` 接入步骤。
3. 已登记但未完成登录/授权（AList 未挂载、OAuth 未授权）：输出 `not_ready` 状态和对应盘的操作路径，不做“假装能下”。
4. 上述所有盘均受“单实例/续传/低速度/失败分类”硬规则约束，见 `references/39-单实例与续传安全.md`。
