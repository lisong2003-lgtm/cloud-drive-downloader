# 34 · 免客户端一键部署（NAS Docker / 本机 / 网页书签）

> 目标：不装 BaiduPCS-Go、aliyunpan、quark-cli、迅雷等任何客户端。
> 引擎一次装在 NAS Docker 里，之后所有下载复用同一容器。

## 一、NAS Docker 一键拉起（推荐，一次 5 分钟）

```bash
# 在 NAS（群晖/飞牛/威联通）上，SSH 进入后：
cd <你的网盘通目录>        # 或你的技能目录
docker compose -f docker/docker-compose.full.yml up -d
```

> compose 已使用上级目录的 `data/`、`download/`，并内置 223.5.5.5 / 119.29.29.29 DNS，避免容器无法解析域名。

三个容器：
| 容器 | 端口 | 作用 |
|---|---|---|
| cdd-alist | 5244 | 多网盘统一 Web 端（登录各网盘授权一次即可） |
| cdd-aria2 | 6800 | BT/磁力/HTTP 多线程下载引擎 |
| cdd-rclone | —   | 跨盘转存/同步（sleep 常驻，用 CLI 调） |

## 二、首次配置 AList（只做一次）

1. 浏览器打开 `http://<NAS_IP>:5244/`
2. 默认账号 `admin`，密码看容器日志：`docker logs cdd-alist | grep password`
3. 登录后 → 管理 → 存储 → 添加你的网盘（百度/阿里/夸克/OneDrive…）按提示授权
4. 回本机，把 AList 地址告诉 pan：

```bash
python3 scripts/pan.py set --alist-url http://<NAS_IP>:5244
```

## 三、三个下载入口

### A. Agent / MCP（Codex 对话里）
```json
{"name":"pan_get","arguments":{"url":"<链接>","dry_run":true}}
```
确认计划后把 `dry_run` 改成 `false` 即真实下载。

### B. CLI / NAS 远程
```bash
python3 scripts/pan.py get "<链接>" --to /tmp/pan-sd --dry-run
python3 scripts/pan.py remote get nas "<链接>" --to <你的下载目录>
```

### C. 网页书签（免安装浏览器扩展）
1. 启动 `python3 scripts/pan.py serve`（或 NAS 上 `pan serve --host 0.0.0.0`）
2. 浏览器打开 `http://<NAS_IP>:17890/bookmarklet.js`
3. 把地址栏整段拖到书签栏（或复制内容新建书签，地址填 javascript:…）
4. 在任意网页点书签 → 弹框选链接 → 回车 → 文件落到 NAS 的 `download/` 目录

## 四、验证
```bash
docker compose -f docker/docker-compose.full.yml config      # 语法
curl -s http://<NAS_IP>:5244/api/public/settings | head -c 200
python3 scripts/pan.py doctor --json
```

## 五、边界
- AList 授权由各网盘官方 OAuth 完成，Skill 不接触 Cookie/Token。
- 不承诺"不限速"；平台/工具限制如实透传。
- 下载内容合法性由用户自行确认。
