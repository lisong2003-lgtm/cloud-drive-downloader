# 123 云盘

## 链接形态

- 常见分享：`https://www.123pan.com/s/xxxx`，也可能出现 `123684.com`、`123912.com`、`123865.com`。
- 分享可能需要提取码，文件夹分享通常先转存再下载。

## 推荐通道

| 通道 | 适用 | 说明 |
|---|---|---|
| AList 123 云盘驱动 | 个人自用 | 用账号 Cookie/登录态挂载 |
| 123 网页/客户端 | 前置操作 | 分享链接转存到自己账号 |
| aria2/curl | 仅直链 | 已经拿到有效直链时才使用 |

## 登录

1. 浏览器登录 `123pan.com`，在 AList 中添加“123 云盘”存储，按驱动提示填写 Cookie/账号。
2. 登记 AList 地址：

```bash
python3 scripts/pan.py set --alist-url "http://127.0.0.1:5244"
```

3. 先转存分享，再按 AList 路径下载：

```bash
python3 scripts/pan.py get "<123分享链接>" --path "/123云盘/目标文件夹" --dry-run
python3 scripts/pan.py get "<123分享链接>" --path "/123云盘/目标文件夹"
```

## 免费 / 会员

- 免费账号：平台可能限速、限制并发；本技能默认单线程、断点续传。
- 会员：`set-drive 123pan --tier vip` 只调整并发，不绕过官方限制。

## 常见错误

| 现象 | 处理 |
|---|---|
| Cookie 失效 | 重新登录并刷新 AList 存储 |
| 分享链接识别为直链 | 确认域名是否属于 123 云盘，必要时用 `--engine` 指定 |
| 路径找不到 | 先在 AList 中刷新目录，确认挂载路径 |

## 风险提示

123 云盘接口和分享规则可能变化；第三方驱动的登录态按密码保管，建议使用小号。
