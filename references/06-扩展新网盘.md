# 扩展新网盘

## 方式一：自定义命令模板（不改代码）

编辑 `~/.config/pan-downloader/config.json`：

```json
{
  "extensions": {
    "mydisk": {
      "name": "某企业网盘",
      "domains": ["pan.example.com"],
      "engine_command": "mytool get {url} --pwd {pwd} --to {dir}"
    }
  }
}
```

或直接登记到某个已识别网盘：

```bash
python3 scripts/pan.py set-drive chengtong \
  --engine-command '你的城通CLI download {url} --pwd {pwd} --out {dir}'
```

占位符：

| 占位符 | 含义 |
|---|---|
| `{url}` | 分享链接或直链 |
| `{pwd}` | 提取码，没有则为空 |
| `{dir}` | 本次任务目录 |
| `{name}` | 网盘显示名 |
| `{tier}` | `free` / `vip` |

验证：

```bash
python3 scripts/pan.py detect "https://pan.example.com/s/xxx"
python3 scripts/pan.py get "https://pan.example.com/s/xxx" --dry-run
```

## 方式二：新增内置驱动

1. 在 `scripts/pan.py` 的 `DRIVES` 加域名与推荐引擎。
2. 在 `build_plan` 里加该引擎的命令拼装。
3. 在 `ENGINE_BINARIES` 加可执行文件名。
4. 在 `DEFAULT_CONFIG["drives"]` 加默认开关。
5. 在 `references/` 加一份该网盘的登录说明。
6. 跑 `PYTHONDONTWRITEBYTECODE=1 python3 scripts/self_test.py`，保证 `SELF_TEST_OK`。

## AList / rclone / WebDAV 接入

- AList：登记 `engines.alist_url`，在 AList 中添加网盘驱动；分享先转存，再用 `--path` 指向 AList 目录。
- rclone：给 AList WebDAV 配 remote，登记 `engines.rclone_remote`；目录使用 `rclone copy`，单文件才回退 curl。
- 通用 WebDAV：登记 `engines.webdav_url/user/password`；坚果云必须使用“应用密码”。

## 安全边界

- 接入任何第三方 CLI 前先确认它把凭据存在本机、不会上传。
- 公司内部资料不要通过云盘通道上传；本技能默认只做“下载到本地”。
- 新网盘先用 `--dry-run` 验证命令，再执行真实下载。
- 不绕过会员、验证码、限速、广告或风控。
