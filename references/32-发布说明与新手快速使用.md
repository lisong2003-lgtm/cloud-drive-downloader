# 网盘通 · 发布说明与新手快速使用

## 一、发布文案（可直接脱敏后用于 SkillHub / GitHub / 社区介绍）

> **一句话：把网盘链接丢给这个工具，它帮你下载，不用装各家网盘客户端。**
>
> 问我“怎么下载百度/夸克/天翼/迅雷/115/123/蓝奏/微云/OneDrive/Google Drive 的资源？”
> 我统一做四件事：识别链接来自哪个网盘 → 引导官方登录或授权 → 规划下载目录 → 调用共享下载引擎落盘到本机或 NAS/远程设备。
>
> 支持 30+ 网盘 + 直链；提供 Web 网页控制台（任务中心、实时速度、剩余时间、完成大小）、剪贴板监听、浏览器扩展、Agent/MCP 接口和远程 NAS 部署。
> 凭据走系统钥匙串，不落明文、不进聊天、不传第三方云。
>
> 边界坦白：不破解会员、不限速、不绕过验证码或风控；部分网盘首次仍需官方扫码/网页授权一次。

## 三、对新手：3 步开始用（最省心版）

```bash
# 第 1 步：安装/配置（一次）
python3 scripts/pan.py setup --apply          # macOS/Linux
scripts\pan.cmd setup --apply                 # Windows
```
```bash
# 第 2 步：打开网页下载助手（常驻）
sh scripts/pan_web.sh                          # 自动启动服务+剪贴板监听+打开浏览器
powershell -ExecutionPolicy Bypass -File scripts\pan_web.ps1   # Windows
```
```bash
# 第 3 步：粘贴链接下载
# 网页首页「粘贴链接开始下载」→ 填链接(+提取码) → 点开始 → 自动跳实时进度
```

路径解释：
- 默认下载目录：Windows `Downloads\网盘下载`；macOS/Linux `~/Downloads/网盘下载`。
- 部分网盘首次要扫码/网页登录一次，这是官方要求，工具不绕过。

## 四、面向“想更快上手”的成员：推荐三条路

1. **完全小白**：先只教第 2 步打开网页 + 第 3 步粘贴链接，不要讲 CLI。
2. **复制即下**：开 `clipboard_monitor`，复制链接自动入队（对日常用户最省事）。
3. **Agent 用户**：直接说“把这个链接下载到 NAS 影视库”，调 Agent/MCP 完成。

## 五、发布时建议附的“不要误会”清单

- 不是网盘官方客户端，不伪装成某个产品/人物。
- 免费档按官方限速执行，不承诺更快；会员只做本机并发调度。
- 需要“能运行 Python 3”的电脑；Windows 要勾选 Add python.exe to PATH。
- 密码/Cookie/Token 只存系统钥匙串，不存明文、不进聊天、不进 Git、不上传云端。
- 公司资料只下载到公司控制的设备或介质，不传第三方云。
