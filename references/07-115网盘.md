# 115 网盘

## 链接形态

- 分享链接：`https://115.com/s/xxxx`、`https://anxia.com/s/xxxx`、`115cdn.com` 或 `115.com.cn` 分享域名。
- 有的分享需要提取码，有的直接打开；转存后的文件夹在“我的网盘”里。

## 推荐通道

| 通道 | 适用 | 说明 |
|---|---|---|
| AList 115 驱动 | 个人自用 | 用 Cookie 或扫码授权把 115 挂载到 AList |
| 115 网页/客户端 | 前置操作 | 分享链接先转存到自己账号，再交给 AList 下载 |
| 115 官方开放能力 | 有额度的场景 | 分享转存和下载能力以后台/额度为准 |

## 登录

1. 浏览器登录 `115.com`，按 AList 115 驱动的提示获取 Cookie，或使用驱动支持的扫码登录。
2. 在 AList 添加“115 网盘”存储，完成连接测试。
3. 在本技能登记 AList：

```bash
python3 scripts/pan.py set --alist-url "http://127.0.0.1:5244"
```

4. 分享先转存到自己的 115 账号；下载时用 AList 路径：

```bash
python3 scripts/pan.py get "<115分享链接>" --path "/115网盘/目标文件夹" --dry-run
python3 scripts/pan.py get "<115分享链接>" --path "/115网盘/目标文件夹"
```

## 免费 / 会员

- 免费账号：受 115 官方下载速度和并发限制，默认单线程、3 次重试、断点续传。
- 会员：`python3 scripts/pan.py set-drive 115 --tier vip` 只影响调度并发，不绕过平台限制。

## 常见错误

| 现象 | 处理 |
|---|---|
| Cookie 失效或要求验证 | 在 AList 中重新登录 115 存储 |
| 分享无法转存 | 检查分享是否有效、是否限制转存、账号是否登录 |
| 路径不存在 | 在 AList 刷新 115 存储，确认挂载目录名 |

## 风险提示

Cookie 等同登录态，建议使用小号；不要把 Cookie 放进聊天、Git 或网盘。第三方驱动接口可能随 115 策略变化。
