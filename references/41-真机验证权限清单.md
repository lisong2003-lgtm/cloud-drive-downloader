# 真机验证权限清单（v0.18.3）

> 用途：列出每个已登记网盘做真机（真实账号/真实链接）回归验证时，需要用户提供的最小授权方式与验收动作。
> 原则：凭据只进系统凭据库，不进入聊天、配置、日志与发布包；未授权前，对应盘一律标记「待用户提供」，不伪造真机结果。

## 总则

1. 每个盘至少 1 个真机下载结果（10 MB 级别小文件），记录盘名、桥类型、结果、耗时。
2. 本轮（2026-10-18）尚未取得用户授权/凭据，下表全部标记「待用户提供」；获得授权后逐盘回填状态。
3. 未验证的盘一律写「不支持/需接入」或「待用户提供」，不承诺不存在的功能。
4. 授权方式必须是官方扫码 / 官方网页登录 / 官方 OAuth / 用户自建的 AList / WebDAV；不允许代填密码、伪造会话、绕过验证码/风控/DRM。
5. 凭据落点统一走系统凭据库：`pan secret set <名称>`（macOS Keychain / Windows Credential Manager / Linux secret-tool）。


## 红线提醒

- 不逆向、不破解登录/风控/DRM。
- 公司数据、未授权内容不回传云平台；下载前确认有权访问。
- 失败一律如实记录：login_required / dlink_missing / captcha / risk_control / http_403 / not_found / disk_full / throttle。
