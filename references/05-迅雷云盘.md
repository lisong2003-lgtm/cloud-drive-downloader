# 迅雷云盘

## 现实情况

迅雷开放平台提供的是 **通用 HTTP 下载 SDK**，并非云盘内容 API；云盘内容下载依赖第三方 `refresh_token`/Cookie 方案（如 AList 迅雷驱动）。非官方通道，需要接受可能失效的风险。

## 用 AList 接入

1. 启动 AList，添加“迅雷云盘”存储，填 refresh_token 或按驱动提示登录。
2. 登记 AList 地址：

```bash
python3 scripts/pan.py set --alist-url "http://127.0.0.1:5244"
```

3. 分享链接先转存到自己迅雷账号，再按 AList 路径下载：

```bash
python3 scripts/pan.py get "<分享链接>" --path "/迅雷云盘/目标文件夹" --dry-run
```

## 免费 / 会员

- 免费账号：迅雷对非会员通常限速；默认单线程、断点续传。
- 会员：`set-drive thunder --tier vip`，仅调整调度并发。

## 风险提示

- refresh_token 等同登录态，泄露等于账号被登录。
- 非官方接口可能随迅雷版本变化，失效时优先更新 AList/驱动。
