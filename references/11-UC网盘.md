# UC 网盘

## 链接形态

- `https://drive.uc.cn/s/xxxx`、`https://pan.uc.cn/...`、`https://fast.uc.cn/...`。
- 分享通常需要转存到自己的 UC 账号后再下载。

## 推荐通道

| 通道 | 适用 | 说明 |
|---|---|---|
| AList UC 网盘驱动 | 个人自用 | 用 Cookie/登录态挂载 |
| UC 网页/客户端 | 前置操作 | 分享先转存 |
| 夸克/UC 系 CLI | 有对应工具时 | 用自定义引擎接入 |

## 登录

1. 浏览器登录 UC 网盘，按 AList“UC 网盘”驱动的提示获取 Cookie 或完成登录。
2. 登记 AList：

```bash
python3 scripts/pan.py set --alist-url "http://127.0.0.1:5244"
```

3. 分享转存后下载：

```bash
python3 scripts/pan.py get "<UC分享链接>" --path "/UC网盘/目标文件夹" --dry-run
python3 scripts/pan.py get "<UC分享链接>" --path "/UC网盘/目标文件夹"
```

## 免费 / 会员

- 免费账号：受官方限速和并发限制，默认单线程、断点续传。
- 会员：`set-drive uc --tier vip` 只调整调度并发，不绕过官方限制。

## 常见错误

| 现象 | 处理 |
|---|---|
| Cookie 失效 | 重新登录 UC 并刷新 AList 存储 |
| 分享转存失败 | 先在 UC 网页/客户端手动转存 |
| 路径找不到 | 刷新 AList 目录，确认挂载名 |

## 风险提示

Cookie 等同登录态；第三方驱动可能随 UC 策略变化，建议使用小号。
