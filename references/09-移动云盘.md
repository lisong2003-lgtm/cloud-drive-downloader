# 移动云盘 / 和彩云

## 链接形态

- `https://yun.139.com/...`、`https://cloud.139.com/...`、`https://caiyun.139.com/...`。
- 常见为分享页链接，可能需要登录移动账号或提取码。

## 推荐通道

| 通道 | 适用 | 说明 |
|---|---|---|
| AList 移动云盘驱动 | 个人自用 | 用 Cookie/账号登录挂载 |
| 移动云盘网页/客户端 | 前置操作 | 先把分享转存到自己账号 |
| 官方开放平台 | 企业/合作方 | 个人接入门槛较高 |

## 登录

1. 浏览器登录移动云盘，按 AList“移动云盘/和彩云”驱动的提示获取 Cookie 或完成登录。
2. 登记 AList：

```bash
python3 scripts/pan.py set --alist-url "http://127.0.0.1:5244"
```

3. 分享转存后下载：

```bash
python3 scripts/pan.py get "<移动云盘分享链接>" --path "/移动云盘/目标文件夹" --dry-run
python3 scripts/pan.py get "<移动云盘分享链接>" --path "/移动云盘/目标文件夹"
```

## 免费 / 会员

- 免费账号：受平台限速和并发限制，默认单线程、3 次重试。
- 会员：`set-drive 139yun --tier vip` 仅调整调度并发，不改变平台限制。

## 常见错误

| 现象 | 处理 |
|---|---|
| 登录态过期 | 在 AList 中重新登录移动云盘 |
| 分享转存失败 | 先用网页版手动转存一次 |
| 挂载路径为空 | 刷新 AList 存储并核对目录名 |

## 风险提示

Cookie/登录态等同账号凭证，建议使用小号；非官方驱动可能随平台策略变化。
