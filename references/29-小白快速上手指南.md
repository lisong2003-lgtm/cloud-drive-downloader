# 多网盘统一下载助手 · 小白快速上手指南

> 面向完全没碰过代码的人。跟着做，10 分钟内能发出第一个下载任务。

## 这个工具是干嘛的？

一句话：**你复制网盘链接，它帮你把文件下载到电脑，还给你一个网页看下载速度和进度。**

以前你下载百度网盘、夸克、天翼、蓝奏、123 等文件，要装好几个客户端、挨个登录、还可能被限速。这个助手把 30 多个网盘统一到一个入口：**复制链接 → 粘贴到网页 → 下载完成**。

- ✅ 免费、本机运行，不把你的文件传到第三方云
- ✅ 网页界面，看得见实时速度、剩余时间、完成大小
- ✅ 支持大量国内网盘 + 国际网盘 + 直链
- ✅ 可选后台常驻、剪贴板自动监听、NAS/远程设备下载

> 注意：它不绕过网盘官方限速、验证码或风控；部分网盘仍要你按官方要求扫码/登录一次，这是网盘账号本身的规则。

---

## 第一步：装好 Python（只做一次，约 5 分钟）

电脑要先有 Python 3.9 或更高版本。

- **Windows**：到 <https://python.org> 下载安装包，运行时一定要勾选 **“Add python.exe to PATH”**。
- **macOS / Linux**：打开“终端”（Terminal），输入：
  ```bash
  python3 --version
  ```
  能显示 `Python 3.9+` 就行；显示不了就先去 python.org 安装。

---

## 第二步：拿到工具

这个技能会以“技能包”（zip）形式分发。把压缩包解压到电脑任意位置，例如桌面上的 `pan-downloader` 文件夹。

以后打开终端/命令提示符，先进入这个目录：

- macOS / Linux：
  ```bash
  cd ~/Desktop/pan-downloader
  ```
- Windows（命令提示符 CMD）：
  ```bat
  cd /d %USERPROFILE%\Desktop\pan-downloader
  ```

> 文件夹内应该有 `scripts` 目录，里面是真正干活的程序。

---

## 第三步：一键配置（只做一次）

在终端里运行：

```bash
# macOS / Linux
python3 scripts/pan.py setup --apply

# Windows
scripts\pan.cmd setup --apply
```

它会自动：
1. 创建配置文件；
2. 检查缺不缺 `rclone` / `aria2` / `curl` 等下载引擎，能装的帮你装；
3. 提示默认下载目录（一般用系统“下载/网盘下载”）。

装完可以不重启电脑。

---

## 第四步：用网页下载（推荐小白走这条路）

### 4.1 打开网页助手

在终端里运行：

```bash
# macOS / Linux
sh scripts/pan_web.sh

# Windows（在脚本目录外的项目根目录里，用 PowerShell）
powershell -ExecutionPolicy Bypass -File scripts/pan_web.ps1
```

会自动弹出浏览器，打开 `http://127.0.0.1:17890/`。这就是你的**个人下载控制台**。

### 4.2 开始第一个下载

1. 在网盘 App/网页里复制某个文件的分享链接（比如带提取码的）。
2. 回到这个网页，最上方有个“**粘贴链接开始下载**”，把链接粘进去。
3. 有提取码就一起填上，点 **开始下载**。
4. 页面会自动跳到“实时进度”视图，你就看得到速度、剩余时间、已完成大小。

> 小贴士：也可以在浏览器旁边开着这个网页，从别处复制链接后**立刻自动入队**（剪贴板监听功能），非常省事。

---

## 第五步：下载完成后去哪找文件？

默认位置：

- Windows：`你的用户目录\Downloads\网盘下载`
- macOS/Linux：`~/Downloads/网盘下载`

网页任务中心里也有每个任务的完成情况，失败的任务能直接点“重试”。

---

## 常见疑问（小白版）

| 你遇到的情况 | 怎么办 |
|---|---|
| 网页打不开 | 确认端口没被占用；再运行一次 `sh scripts/pan_web.sh` |
| 提示缺少 rclone/aria2 | 用 `python3 scripts/pan.py setup --apply` 帮你装 |
| 百度/夸克要扫码登录 | 这是网盘官方要求，按提示完成一次授权即可，工具不绕过 |
| 下载很慢 | 免费网盘普遍限速，工具按平台免费档执行，不承诺“破解提速” |
| 提示提取码错误 | 核对分享是否要密码，把提取码和链接一起放进去 |
| 想存到别的文件夹 | 下载时在网页“目标目录”一栏填完整路径 |
