# 夸克网盘

## 现实情况

夸克网盘没有公开的官方开放 API；社区可用方案是 **Cookie 登录的第三方 CLI 或 AList 夸克驱动**。属于非官方通道，接口随时可能变化，建议小号使用。

## 登录（一次）

1. 浏览器登录 `pan.quark.cn`。
2. 开发者工具 → Application → Cookies，复制关键 Cookie（常见为 `__puus`、`__uid`、`__kp` 等，以工具要求为准）。
3. 把 Cookie 写入本机凭据文件，并用工具自己的命令完成登录。Cookie 等同登录态，按密码级别保管。

## 用自定义引擎接入

任意支持“夸克分享链接 + 提取码 + 输出目录”的 CLI 都可以挂进来：

```bash
python3 scripts/pan.py set-drive quark \
  --engine-command 'quark download {url} --pwd {pwd} --dir {dir}'
```

然后用：

```bash
python3 scripts/pan.py get "https://pan.quark.cn/s/xxxx" --pwd 1234 --dry-run
```

若走 AList：在 AList 添加“夸克网盘”存储（填 Cookie），把分享转存到自己账号后用 `--path /夸克网盘/目录` 下载。

## 免费 / 会员

- 免费账号：限速、并发限制由夸克决定，默认单线程断点续传。
- 会员：`set-drive quark --tier vip` 仅调整调度，不绕过平台限制。

## 风险提示

- 非官方接口可能失效，失效时更新 CLI/AList 版本即可。
- 不要用主号；不要在第三方网站填账号密码。
