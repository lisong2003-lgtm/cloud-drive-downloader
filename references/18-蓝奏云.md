# 蓝奏云 / 新蓝奏

## 链接形态

- 常见域名很多：`lanzou.com`、`lanzoui.com`、`lanzoux.com`、`lanzouw.com`、`lanzoup.com`、`lanzoub.com`、`lanzoue.com`、`lanzous.com`、`lanzoa.com`、`lanzn.com`、`ilanzou.com`。
- 分享通常是小文件，可能需要提取码；域名经常更换。

## 推荐通道

| 通道 | 适用 | 说明 |
|---|---|---|
| AList 蓝奏云驱动 | 个人自用 | 用 Cookie/登录态挂载 |
| 浏览器直下 | 小文件 | 手动打开分享页，确认能下载 |
| 自定义 CLI | 驱动失效时 | 用 `engine_command` 接入维护中的工具 |

## 登录

1. 浏览器登录蓝奏云，按 AList“蓝奏云”驱动的提示获取 Cookie/登录信息。
2. 登记 AList：

```bash
python3 scripts/pan.py set --alist-url "http://127.0.0.1:5244"
```

3. 转存后下载：

```bash
python3 scripts/pan.py get "<蓝奏云分享链接>" --pwd 提取码 --path "/蓝奏云/目标文件夹" --dry-run
python3 scripts/pan.py get "<蓝奏云分享链接>" --pwd 提取码 --path "/蓝奏云/目标文件夹"
```

## 免费 / 会员

- 免费账号：蓝奏云通常不限速，但广告、验证码和域名变化会影响自动化。
- 会员：`set-drive lanzou --tier vip` 只调整调度并发，不绕过验证码/风控。

## 常见错误

| 现象 | 处理 |
|---|---|
| 域名无法识别 | 先用 `detect`，必要时在 `extensions` 增加新域名 |
| 驱动失效 | 更新 AList 或改用维护中的自定义 CLI |
| 验证码/风控 | 回浏览器手动下载，不连续请求 |

## 风险提示

不要尝试绕过验证码和广告风控；只在获得授权的资源上使用。
