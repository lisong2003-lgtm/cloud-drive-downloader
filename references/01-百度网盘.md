# 百度网盘（免费账号默认）

## 链接形态

- 分享链接：`https://pan.baidu.com/s/1xxxx`，常见提取码 4 位。
- 转存后的文件夹：在“我的资源”里，可用 BaiduPCS-Go 直接下载。

## 现实情况（2026-09 核对）

百度官方开放平台对个人开发者主要开放列目录/上传类接口，**分享转存和下载不对外**；因此本技能走第三方命令行工具 BaiduPCS-Go，属于个人使用层面的非官方通道，接口可能随官方策略变化。

## 登录（一次）

1. 浏览器登录 `pan.baidu.com`。
2. 开发者工具 → Application → Cookies → 复制 `BDUSS` 值。
3. 执行：

```bash
BaiduPCS-Go login -bduss=<你的BDUSS>
```

BDUSS 等同登录态，按密码级别保管；建议用小号，不要用主号。凭据只写在 BaiduPCS-Go 自己的配置里，本技能不复制、不打印。

## 转存 + 下载

```bash
# 1) 分享转存到自己网盘
BaiduPCS-Go transfer "https://pan.baidu.com/s/1xxxx" 1234 /网盘下载

# 2) 从自己网盘下载到本地
BaiduPCS-Go download /网盘下载 --saveto "/Volumes/PanDownloads/网盘下载/百度网盘"
```

技能会自动拼以上两步（先转存、再下载）：

```bash
python3 scripts/pan.py get "https://pan.baidu.com/s/1xxxx" --pwd 1234 --dry-run
python3 scripts/pan.py get "https://pan.baidu.com/s/1xxxx" --pwd 1234
```

## 免费 / 会员

- 免费账号：官方限速明显，建议单线程断点续传 + 夜间挂机；不要频繁重试，容易触发风控。
- 会员：在百度客户端/网页购买后，BaiduPCS-Go 同样享受对应速度；技能不提供任何绕过。

## 常见错误

| 报错 | 原因 | 处理 |
|---|---|---|
| `bduss 已失效` | 登录态过期 | 重新取 BDUSS 并 `login` |
| `转存失败：分享已取消` | 原分享失效 | 让分享者重新生成链接 |
| `下载限速` | 免费账号 | 接受限速或用会员 |
| `请求过于频繁` | 短时间大量操作 | 等 10 分钟以上再试，别连续重试 |
