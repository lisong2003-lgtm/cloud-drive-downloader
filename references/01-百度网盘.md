# 百度网盘（官方网页会话，零客户端）

## 默认流程（v0.16.0）

百度分享链接默认走 `baiduweb` 官方网页会话桥：

```bash
python3 scripts/pan.py probe "https://pan.baidu.com/s/1xxxx?pwd=1234" --json
python3 scripts/pan.py get "https://pan.baidu.com/s/1xxxx?pwd=1234" --to /目标目录 --live
```

执行流程：

1. 识别登录态、提取码、文件夹、子文件夹、单文件、总大小和文件列表。
2. 提取码可写在链接 `?pwd=` 或通过 `--pwd` 提交。
3. 文件夹递归列目录；本地按分享内相对路径建同名目录。
4. 每个文件拆成独立任务，单独请求官方下载直链，失败只标记该文件。
5. 直链用 `.part` 断点续传；同路径、同大小且已完整的文件跳过。
6. Web UI 粘贴链接后立即投递（粘贴 0ms、输入防抖 120ms），受理后立刻回执耗时与 `/live` 地址，进度每 10 秒刷新。

## 会话与安全边界

- 使用进程内 `CookieJar` 保存匿名网页会话；不读取浏览器 Cookie。
- 用户不需要、也不应该向工具粘贴 `BDUSS` / `STOKEN` / Cookie。
- 日志、报告和 Web API 会脱敏 URL 里的 `pwd` 等敏感参数。
- 遇到验证码、风控、会员、付费或平台限制时安全失败；不破解、不绕过。

## 常见状态

| 状态 | 含义 | 处理 |
|---|---|---|
| `web_session` | 已建立匿名官方网页会话 | 可继续尝试下载 |
| `captcha_required` | 官方接口要求验证码 | 在官方网页完成验证后再试；工具不替代验证码 |
| `platform_denied` | 官方返回“违规操作” | 不能下载；等待分享者调整链接或改用授权渠道 |
| `auth_required` | 页面要求登录态 | 在浏览器登录后重试；不要粘贴 Cookie |
| `password_invalid` | 提取码错误或提取会话失效 | 核对提取码后重试 |
| `member_required` | 会员/付费限制 | 不绕过；按官方授权方式处理 |

## 分享需要登录时（官方扫码）

匿名会话对**公开分享**有效；一旦官方返回 `auth_required` / `dlink_missing`
（大文件、非公开分享、或分享者限制了匿名下载），必须补登录态，走官方扫码：

```bash
# 1) 用百度网盘 App 扫码，登录态写入 BaiduPCS-Go（凭据不进聊天）
python3 scripts/pan.py login baidu --qr

# 2) 分享文件先转存到自己网盘，再用兼容引擎下载
python3 scripts/pan.py get "https://pan.baidu.com/s/1xxxx?pwd=1234" --engine baidupcs --to /目标目录 --live
```

报告里的 `login_required: true` 与 `remediation` 字段会直接给出这组命令；
`get` 失败时终端也会打印 `⚠️ 需要处理：...`。

## 兼容回退

`baidupcs` 依赖第三方 BaiduPCS-Go，需要一次官方扫码登录；匿名 `baiduweb` 拿不到直链时使用它：

```bash
python3 scripts/pan.py get "https://pan.baidu.com/s/1xxxx?pwd=1234" --engine baidupcs
```

## 常见错误

| 报错 | 原因 | 处理 |
|---|---|---|
| `bduss 已失效` | 显式回退通道的第三方登录态过期 | 不要粘贴 Cookie；优先用官方网页会话桥 |
| `转存失败：分享已取消` | 原分享失效 | 让分享者重新生成链接 |
| `请求过于频繁` | 短时间大量操作 | 等 10 分钟以上，不要连续重试 |
| `errno=-20` / `errno=118` | 验证码或平台限制 | 如实失败，不绕过 |
