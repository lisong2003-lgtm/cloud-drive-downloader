# 跨盘转存与增量同步（v0.6.1-R4 新增）

用在 **AList 已挂载多个存储 / rclone 已配置 remote** 的场景，把 A 盘目录转存到 B 盘，或做增量同步。默认只打印 dry-run，不会实际写入；目标命中公司数据红线时默认拒绝。

## 命令

```bash
python3 scripts/pan.py transfer <源路径> <目标路径>            # 只打印 dry-run 计划
python3 scripts/pan.py transfer <源路径> <目标路径> --apply     # 实际执行 rclone copy
python3 scripts/pan.py sync <源路径> <目标路径> --delete --apply  # 增量同步（会删目标多余文件）
python3 scripts/pan.py transfer src: dir:// -> dst: --json      # 给 Agent 输出 JSON 计划
```

路径写法与 rclone 一致：`remote名:目录`（如 `alist:源/目录`、`nas:backup/01`），或本机路径。`--transfers N / --checkers N` 可调并发（默认读 `config.json` 的 `transfer` 段：4/8）。

## 安全红线

- 默认 `transfer` / `sync` 都只打印 dry-run，不会写入；`--apply` 才真正执行。
- `sync` 会删除目标里源没有的文件，必须先显式 `--delete` 再 `--apply`，否则直接报错（返回码 3）。
- 目标路径命中公司目录（办公/拓展卷、公司知识库等）时默认拒绝（返回码 4），除非显式 `--allow-company-dest` 或配置 `transfer.allow_company_dest=true`。公司数据默认仍只下载不上传。
- 依赖 `rclone` 已安装：`brew install rclone`；未装时报错（返回码 2），不假装成功。

## 验证

先用 `pan.py doctor` 确认识别到 rclone；再 `transfer <源> <目标>` 看 dry-run 计划，核对路径后才 `--apply`。成功输出 `✅ transfer 完成`。
