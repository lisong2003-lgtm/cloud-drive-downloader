# 真机验证清单（v0.6.1-R5）

沙箱里无法完成的真实回归，请在本机跑一次。自动化脚本：`scripts/verify_real_env.py`。

## 一步到位

```bash
cd /Users/lis/.codex/skills/cloud-drive-downloader
python3 scripts/verify_real_env.py
# 可选：换真实直链测 Range 分片
python3 scripts/verify_real_env.py --split-url "https://example.com/big.iso"
# 可选：rclone 跨盘 dry-run（需要已装 rclone 并配置 remote）
python3 scripts/verify_real_env.py --transfer-src alist:src/a --transfer-dst alist:bak/a
```

脚本会依次输出 `PASS / FAIL / SKIP`，并打印可执行补充命令；最后输出 `VERIFY_REAL_ENV_DONE`。

### 逐项对应

| 项 | 沙箱不能做 | 本机验证方法 | 验收标准 |
|---|---|---|---|
| Range 分片真实下载 | 不能绑定网络端口 | `verify_real_env.py`（默认起本地 8MB 文件 + `--split 4`）；或对真实直链 `pan.py get URL --split 4` | 文件字节数一致、`下载报告.json` 出现，`ok=true` |
| rclone 转存/同步 | 未装 rclone、无法真实跨盘 | `brew install rclone` → `rclone config` 配 remote → `verify_real_env.py --transfer-*` 看 dry-run | transfer dry-run 计划 `ok=true`；确认后 `--apply` 实测 |
| MCP 注册 | 改 config.toml 属系统配置 | 按 `references/23-MCP与Agent接口.md` 在 `[mcp_servers]` 注册 → 重启 Codex → 在对话里看到 `pan_doctor` 工具 | `initialize` 有响应；Codex 能列出 4 个 pan 工具 |
| 通知发送 | 无真实 webhook | `pan secret set notify.work_weixin --stdin`（存 URL）→ `pan notify send --title 测试 --body hi`（dry-run）→ 加 `--send` | dry-run 输出 JSON 渲染；真实 `--send` 目标收到消息 |
| 事件流/报告 | 沙箱可用（已验证） | `pan.py get <可下载直链> --events` | 每步骤一行 JSON，修改后 report `ok=true` |

## 红线不变

- rclone 转存默认只 dry-run；`--apply` 才接入真实写入。
- 公司目录默认拒绝写入（`--allow-company-dest` 才放行）。
- `sync` 必须显式 `--delete + --apply`，不改默认删除动作。
- 通知 webhook 地址只存系统凭据库，不写配置、不进日志、不回显。
