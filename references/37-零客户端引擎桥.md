# 37 · 零客户端引擎桥

> 目标：用户不需要安装百度网盘、夸克、迅雷等桌面客户端；优先复用官方网页会话、浏览器、AList、OAuth/WebDAV 和网盘通内置下载器。

## 1. 四类桥

1. **官方网页会话桥（推荐）**
   - 通过官方分享页请求页面数据、目录和下载接口。
   - 只使用进程内匿名会话，不读取、不导入浏览器 Cookie。
   - 支持识别提取码、文件夹、子文件夹、单文件、总大小和文件列表。
   - 平台允许时用官方直链断点续传；要求验证码、风控、会员或付费时安全失败。
   - v0.16.0 已接入百度：`baiduweb`。
2. **浏览器直链捕获桥**
   - 用户在官方网页登录并主动点击下载。
   - Chrome/Edge 插件捕获官方生成的下载 URL，不读取登录态。
   - 网盘通用内置 HTTPDownloader / aria2 续传。
3. **AList 驱动桥**
   - AList 添加网盘存储并完成官方授权。
   - 分享文件先转存到自己网盘。
   - 通过 WebDAV / rclone / HTTP 统一下载。
4. **官方 OAuth / WebDAV 桥**
   - 适用于 OneDrive、Google Drive、Dropbox、坚果云等。
   - 凭据只进系统凭据库，不经聊天。

## 2. 分网盘建议

- 百度：官方网页会话桥 > 浏览器直链桥 > AList 桥；桌面客户端只作为显式兼容回退。
- 夸克 / 115 / 123 / 天翼 / 迅雷 / 微云 / 蓝奏：浏览器直链桥 > AList 桥；桌面客户端只作为显式兼容回退。
- OneDrive / Google Drive / Dropbox / Mega / pCloud / Proton Drive：OAuth / AList 优先。
- 坚果云 / 通用 WebDAV：官方应用密码 + WebDAV。
- HTTP 直链 / 公开流媒体 / BT：直接用内置 HTTPDownloader、aria2、yt-dlp，不需要网盘客户端。

## 3. 插件行为

- 默认开启“捕获官方网页触发的直链”。
- 插件不读取 Cookie、不读取登录态、不解析网盘页面。
- 捕获的是用户主动触发的下载 URL；如果 URL 需要登录态且浏览器下载能继续，不代表网盘通一定能独立续传。

## 4. 通用桥复用

`webengine.py` 是调度层：分享探测、递归列目录、同名目录还原、逐文件任务、`.part` 断点续传、失败重试和实时进度回调由通用层完成；各网盘驱动只补页面解析和官方接口。

## 5. 边界

- “零客户端”指不安装各家桌面客户端，不等于零依赖。
- Python 是网盘通运行基础；浏览器插件用于捕获官方直链。
- AList 是可选统一服务桥，不是必装项。
- 官方不给直链、要求客户端、限制会员、需要风控验证时，工具必须如实失败。
