# 其他网盘

本文件覆盖已登记但使用频率较低的网盘。共同规则：先用 AList 挂载对应驱动并转存到自己账号；如果当前 AList 已不支持该盘，则用 `set-drive <盘> --engine-command '...'` 接入维护中的 CLI。所有盘都默认免费账号单线程、3 次重试、断点续传；`tier=vip` 只调整并发。

## 悟空网盘

- 域名：`wukong.com`、`pan.wukong.com`。
- 常见为分享页/转存链接。推荐 AList 悟空驱动；驱动不可用时用官方网页转存后自建 CLI。
- 登录态/扫码授权均按密码保管，建议小号。

## 豆包新盘

- 域名：`pan.doubao.com`（技能也保留了豆包相关域名以便识别）。
- 属于较新的分享/存储形态，接口可能快速变化。优先使用 AList 豆包/字节系驱动，失效时用浏览器保存到自己账号。
- 不要把普通豆包聊天页当成网盘直链；用 `pan.py detect` 先确认。

## Mega

- 链接：`https://mega.nz/file/...`、`https://mega.io/...`。
- 推荐 AList Mega 驱动或 rclone Mega 后端。免费账号有传输配额，配额用尽后平台可能限制下载。
- 大文件建议保留任务目录，断点/重试时继续，不要连续创建新任务。

## TeraBox

- 链接：`terabox.com`、`1024terabox.com`、`teraboxapp.com`。
- 推荐 AList TeraBox 驱动；分享先保存到自己账号。免费账号限速/广告/地区限制较常见。
- 不要把 TeraBox 与百度网盘链接混淆，域名不同。

## pCloud

- 链接：`pcloud.com`、`pcloud.link`。
- 推荐 AList pCloud 驱动，OAuth 授权后挂载。免费空间和流量按 pCloud 规则。
- pCloud 的公开链接有时可直接下载；仍建议先确认权限和文件完整性。

## Proton Drive

- 链接：`drive.proton.me`、`proton.me`。
- 推荐 AList Proton Drive 驱动（若当前版本支持），否则用 Proton 官方客户端手动下载。
- 端到端加密，第三方接口兼容性可能有限；不要在不可信工具里输入主密码。

## Yandex Disk

- 链接：`disk.yandex.com`、`disk.yandex.ru`、`yadi.sk`。
- 推荐 AList Yandex Disk 驱动，OAuth/应用密码授权。地区可用性和速度受网络影响。
- 公开分享可能允许直接下载；仍按账号权限操作。

## MediaFire

- 链接：`mediafire.com`。
- 推荐 AList MediaFire 驱动；公开单文件也可直接浏览器下载。免费账号广告/限速明显。
- 大批量文件建议先看目录结构，再递归下载，避免重复请求。

## Trainbit

- 链接：`trainbit.com`。
- 推荐 AList Trainbit 驱动（以当前 AList 版本支持为准）；不支持时用自定义 `engine_command`。
- 免费套餐有空间/流量限制，具体以 Trainbit 页面为准。

## 光雅盘

- 链接：`guangyapan.com`。
- 先尝试 AList 对应驱动；若没有该驱动，用维护中的 CLI：
  `python3 scripts/pan.py set-drive guangyapan --engine-command '工具 下载 {url} --pwd {pwd} -o {dir}'`
- 小站接口变化快，先 `--dry-run` 再下载。

## 飞鸡云

- 链接：`feijipan.com`。
- 优先 AList/官方网页；不支持时用 `engine_command`。注意分享有效期和提取码。
- 不绕过验证码、广告或风控。

## 闪电盘

- 链接：`shandianpan.com`。
- 优先 AList/官方网页；不支持时用 `engine_command`。小站稳定性有限，建议保留日志和失败清单。
- 下载目录由用户指定，默认不落到 iCloud。

## 城通网盘

- 链接：`ctfile.com`、`400gb.com`。
- AList 兼容性不稳定，技能标记为 `custom`。配置示例：

```bash
python3 scripts/pan.py set-drive chengtong \
  --engine-command '你的城通CLI download {url} --pwd {pwd} --out {dir}'
python3 scripts/pan.py get "<城通分享链接>" --dry-run
```

- 城通常见等待/广告/验证码，自动化工具必须以平台规则为准；不要绕过验证码或付费限制。

## 通用错误与安全

| 现象 | 处理 |
|---|---|
| 链接识别成 `direct` | 用 `detect` 检查域名；必要时在 `extensions` 添加域名和引擎 |
| AList 没有对应驱动 | 更新 AList；或用 `set-drive ... --engine-command` 接自定义 CLI |
| 账号被要求验证 | 回官方网页/客户端完成验证，工具不绕验证码 |
| 403/401 | 重新登录或重新授权，不要用主号硬试 |
| 目录只下到一个文件 | 检查是否用了 rclone/AList 递归，而不是 curl 单文件 |

凭据只放 `~/.config/pan-downloader/config.json`（600）或 AList 自己的本机配置；公司资料只下载到本机/公司介质，不上传云盘。
