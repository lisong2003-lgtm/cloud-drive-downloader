# 腾讯微云

## 链接形态

- `https://share.weiyun.com/xxxx`、`https://www.weiyun.com/...`。
- 分享可能需要提取码；文件夹分享建议先转存。

## 推荐通道

| 通道 | 适用 | 说明 |
|---|---|---|
| AList 腾讯微云驱动 | 个人自用 | Cookie/登录态挂载 |
| 微云网页/客户端 | 前置操作 | 分享先转存到自己账号 |
| 自定义 CLI | 驱动不稳定时 | 通过 `engine_command` 接入 |

## 登录

1. 浏览器登录微云，按 AList“腾讯微云”驱动的提示获取 Cookie/登录信息。
2. 登记 AList：

```bash
python3 scripts/pan.py set --alist-url "http://127.0.0.1:5244"
```

3. 转存后下载：

```bash
python3 scripts/pan.py get "<微云分享链接>" --path "/腾讯微云/目标文件夹" --dry-run
python3 scripts/pan.py get "<微云分享链接>" --path "/腾讯微云/目标文件夹"
```

## 免费 / 会员

- 免费账号：速度和并发由微云限制，默认单线程、断点续传。
- 会员：`set-drive weiyun --tier vip` 只调整调度并发，不做绕过。

## 常见错误

| 现象 | 处理 |
|---|---|
| Cookie 失效 | 重新登录微云并刷新 AList 存储 |
| 分享转存失败 | 先在微云网页/客户端手动转存 |
| 路径不存在 | 刷新 AList 目录并核对名称 |

## 风险提示

Cookie 是登录态，不建议用主号；第三方驱动可能随微云策略失效。
