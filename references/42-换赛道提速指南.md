# 42-换赛道提速指南（非会员下载的诚实路径）

> 先说结论：**百度网盘对非会员的限速是账号级 + 接口级的，任何客户端侧手段都绕不开。**
> 本指南不承诺突破限速——它给出的是"绕开被限速的那条路"的四条合法路径，
> 配合本工具的自动分片（v0.20.0 F1）与闲时队列（v0.20.0 F2）把能吃到的速度红利吃满。

## 一、四条换赛道路径对比

| 路径 | 前提 | 速度预期 | 主要限制 | 适合 |
|---|---|---|---|---|
| ① 123 云盘官方 WebDAV | 分享方把文件转存到 123 云盘 | 免费档不限速（官方 WebDAV） | 免费容量有限（约 2TB 内），单文件大小限制 | 常态化小中大文件交换 |
| ② 夸克离线 + quark-cli | 磁力/种子资源（可离线秒传） | 转存快，下载走 quark-cli | 夸克免费档有单日流量限制 | 影视、大文件磁力资源 |
| ③ PikPak 离线 | 磁力资源 | 转存后直链下载快 | 免费额度有限 | 磁力资源的备用通道 |
| ④ 让分享方换盘 | 你能联系到分享方 | 最干净 | 沟通成本 | 长期协作 |

## 二、每条路径怎么接本工具

### ① 123 云盘官方 WebDAV（首推，零客户端）

1. 分享方：把文件上传到 123 云盘，分享给你。
2. 你：在 AList 里添加 123 云盘驱动（官方 WebDAV 或 Open API 均可），或直接用支持 WebDAV 的挂载。
3. 下载：把 AList 生成的 WebDAV 直链交给本工具：
   ```bash
   pan get "http://127.0.0.1:5244/d/123pan/文件.zip" --to ~/Downloads
   # v0.20.0 起：单连接被限且支持 Range 时会自动切分片（AUTO_SPLIT），无需手动 --split
   ```

### ② 夸克离线 + quark-cli

1. 磁力/种子先丢给夸克 App 离线下载（转存到夸克网盘）。
2. `pan setup` 安装 quark-cli 桥（见 references/03-夸克网盘.md）。
3. 用 `pan get <夸克分享链接>` 下载。

### ③ PikPak 离线

1. 磁力丢给 PikPak 离线。
2. 用 PikPak 生成的直链（或 AList 挂载 PikPak 驱动）走 `pan get`。
   见 references/12-PikPak.md。

### ④ 让分享方换盘

直接把本文件发给对方："请用 123 云盘 / 夸克 分享，秒传 + 不限速，双方都省时间。"

## 三、吃满本工具自带的红利（对任何网盘有效）

1. **自动分片（F1）**：`pan get <直链>` 即可——工具先探测 Range、再 1MB 样本测速，
   单连接低于 `http.auto_split_threshold_kbps`（默认 1024）自动按
   `http.split_max_concurrency`（默认 4）切分片；分片级复用让重跑不浪费已下字节。
2. **闲时队列（F2）**：服务端 0-8 点流控松是普遍现象。
   ```bash
   pan idle add "https://..." -- --to ~/Downloads   # 入队
   pan idle run                                      # 常驻守护（前台，Ctrl-C 停）
   pan idle run --print-crontab                      # 想用 cron？只打印条目，装不装你决定
   ```
3. **断点续传**：任何中断重跑同一条命令即可，已完成的分片/字节自动复用。

## 四、明确不做的（与"零客户端"初衷一致）

- **第三方解析站 / 中转直链**：直链要经过别人服务器，文件内容对第三方可见——
  比装官方客户端危险得多。
- **破解客户端 / 改 UA / 进程变速工具**：账号封禁风险 + 恶意软件重灾区；
  进程变速对网络下载这种 I/O 等待型任务本来就无效。
- **逆向网盘协议 / 伪装签名**：触发风控封号，且本工具的合规定位不允许。

## 五、一句话总结

非会员想要快：**换赛道（123/夸克/PikPak 离线）> 闲时下载 > 自动分片 > 等待**。
本工具负责把后三件事自动化；第一件事靠换存储位置，本指南给出接法。
